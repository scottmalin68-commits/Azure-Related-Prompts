## 📂 Prompt Catalog

### 1. **Access Policy Architect — Design Generator**  
**Goal:**  
Create a deterministic, step‑by‑step Azure access policy design workflow. This prompt guides AI systems through **requirements gathering**, **risk scoring**, **Zero Trust alignment**, **policy drafting**, and **validation**.  
**Highlights:**  
- Structured decision tree  
- Repeatable outputs  
- Supports multiple policy types (CA, App Roles, PIM, RBAC)  
- Built‑in misconfiguration detection  

---

### 2. **Conditional Access Policy Analyzer (Deep‑Dive Audit)**  
**Goal:**  
Perform a full‑fidelity audit of Conditional Access policies, including **coverage analysis**, **conflict detection**, and **Zero Trust scoring**.  
**Highlights:**  
- Multi‑layer evaluation logic  
- Policy overlap and gap detection  
- Enterprise‑grade reporting format  

---

### 3. **Conditional Access Policy Simulator**  
**Goal:**  
Simulate user, device, and app scenarios against existing Conditional Access policies to identify **unexpected blocks**, **coverage gaps**, and **policy conflicts**.  
**Highlights:**  
- Scenario‑driven simulation mode  
- Supports multiple personas and environments  
- Outputs structured simulation logs  

---

### 4. **Conditional Access Hardening Advisor**  
**Goal:**  
Provide actionable recommendations to strengthen Conditional Access posture, reduce risk, and align with Zero Trust principles.  
**Highlights:**  
- Risk‑based scoring  
- Policy hygiene checks  
- Hardening roadmap generation  

---

### 5. **Conditional Access Documentation Generator**  
**Goal:**  
Generate clean, structured documentation for Conditional Access policies, suitable for audits, stakeholder review, and architectural planning.  
**Highlights:**  
- Markdown‑ready output  
- Includes policy summaries, rationale, and impact  
- Supports export to GitHub, Confluence, or internal wikis

## 🚀 Usage  
These prompts are optimized for:

- Microsoft Copilot  
- ChatGPT  
- Claude  
- Gemini  
- Any LLM that supports structured reasoning  

**Recommended workflow:**  
1. Copy the prompt into your AI tool.  
2. Provide your environment details or policy set.  
3. Run in **analysis mode** first.  
4. Use **simulation mode** for scenario testing.  
5. Export results into documentation or architecture diagrams.
