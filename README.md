# Azure‑Related Prompts

A focused collection of AI prompts designed to support Azure engineers, architects, and administrators with cloud analysis, identity reasoning, and configuration understanding. Each prompt includes a **Goal** describing its purpose.

## 🎯 Purpose
Provide deterministic, structured prompts that help analyze Azure configurations, reason about identity and access, and simulate cloud behaviors.

## 📂 Prompt Catalog

### **Access Policy Architect — Design Generator**
**Goal:** Generate structured access policy designs aligned with Azure identity and security best practices.

### **Conditional Access Policy Analyzer (Deep‑Dive Audit + Simulation Suite)**
**Goal:** Analyze Conditional Access policies, simulate outcomes, and identify gaps or misconfigurations.

## 🧩 Who This Is For
Azure administrators, cloud security engineers, IAM specialists, and cloud architects.

## 🚀 How to Use
Open any prompt file and follow the embedded instructions.
